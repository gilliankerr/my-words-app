# My Words contributor guidance

Use Node.js 24; npm ci, npm start, npm test and npm run test:frontend are described in README.md and DEVELOPMENT.md. Preserve unrelated work. Do not publish or deploy without operator authority.

Never use real user content, live databases, credentials or paid AI in tests. Keep fixtures fictional and public assets explicitly allow-listed. Retain unknown envelope fields, offline copies, local-first saves, ownership and revision checks, export/restore safeguards and untrusted-text rendering. Stable built-in vocabulary IDs must not be renamed without a deliberate migration/recovery plan.

Design for adults with word-finding difficulties, not presumed impaired understanding. Retain complete wording and visible labelled controls. Keep booklet typography and imposition; inspect generated dense PDFs after print changes. Use Canadian spelling. Keep third-party notices and distinguish MIT code from separately licensed artwork.
